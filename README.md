# Personal Portfolio Website

A responsive personal portfolio website built using HTML, CSS, JavaScript, and Bootstrap.

## Features
- Navigation bar with all required sections
- Home section with introduction and social links
- About Me section with career details
- Education section with academic details
- Skills section with progress bars
- Projects section with live project links
- Contact section with JavaScript validation
- Responsive layout for mobile, tablet, and desktop

## Project Structure
- `index.html` – main page content
- `styles.css` – custom styling
- `script.js` – form validation logic

## How to Run
1. Open the project folder.
2. Start a local server:
   ```bash
   python -m http.server 8000
   ```
3. Open in browser:
   ```text
   http://localhost:8000
   ```
